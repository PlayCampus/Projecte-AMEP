# Playcampus
Per poder conectar una base de dades a l'aplicació s'ha de posar la informació de la base de dades en un fitxer anomenat configuracio.env amb el següent format: DB_USER="usuari" DB_PASS="contrasenya" DB_NAME="nom de la base de dades" DB_HOST="nom del host"

Aquest arxiu ha d'estar localitzat a la mateixa carpeta que l'executable.
