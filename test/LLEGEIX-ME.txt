## ?? COM EXECUTAR

### Opció 1: Script Interactiu Windows
```
cd test
run_tests.bat
```

### Opció 2: PowerShell
```powershell
cd test
.\run_tests.ps1 -Action All
```

### Opció 3: Directe
```bash
cd test
test.exe
```

### Opció 4: Amb Filtres
```bash
test.exe --gtest_filter="ReglesPartitTest*"
test.exe --gtest_filter="*Validacio*"
```

### Opció 5: Generar XML Report
```bash
test.exe --gtest_output="xml:test_results.xml"
```

## ?? CASOS DE PRUEBA

### Validacions Positives (Cas vàlid)
- Dorsal vàlid: 1-99
- Edat vàlida: 16-99
- Dates correctes: inici < fi
- Strings no buits
- Partits amb equips diferents
- Estadístiques positives

### Validacions Negatives (Error espertat)
- Dorsal fora límits
- Edat fora límits
- Dates incorrectes
- Strings buits
- Equips iguals al partit
- Gols negatius

### Casos Límit
- Dorsal: 1 (mín), 99 (màx)
- Edat: 16 (mín), 99 (màx)
- Punts, gols, etc: positius
